Welcome!

I'm an aspiring game designer with a passion for game design, game mechanics, and level design. I enjoy both playing and creating games, and my ideas come from anime, manga, and other games, as well as whatever I happen to be curious about. I've also built solo and collaborative projects using tools like Godot, Twine, Quest, Unity, Unreal Engine, Blender, Inkscape, and Pixelorama.
